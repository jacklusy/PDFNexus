# PDFNexus Web

Next.js 15 App Router frontend for PDFNexus.

## Scripts

- `npm run dev` — development server on :3000
- `npm run build` / `start` — production
- `npm run typecheck` / `lint` / `test`

## Env

See repo root `.env.example`:

- `NEXT_PUBLIC_API_URL` — NestJS API origin (credentials included)
- `NEXT_PUBLIC_APP_URL` — canonical site URL for metadata/sitemap
